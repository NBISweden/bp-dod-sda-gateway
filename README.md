# Big Picture Dataset On Demand Sensitive Data Archive Gateway (bp-dod-sda-gateway)

The bp-dod-sda-gateway is responsible for the On Demand Dataset creation in the BigPicture Project.

## Description

The bp-dod-sda-gateway integrates with:

* The [Metadata-Submitter](https://github.com/CSCfi/metadata-submitter/) Sync API
    * To get the origin dataset metadata.
* The [Metadata-Submitter](https://github.com/CSCfi/metadata-submitter/) Postgres Database
    * To get the origin dataset file accession ids.
* [A Rems](https://github.com/CSCfi/rems/) instance
    * To create the resource and catalog items for created On Demand Datasets
* The [Sensitive Data Archive s3inbox](https://github.com/neicnordic/sensitive-data-archive/blob/main/sda/cmd/s3inbox/s3inbox.md)
    * To upload the generated metadata files for the requested On Demand Dataset
* The [Sensitive Data Archive api](https://github.com/neicnordic/sensitive-data-archive/blob/main/sda/cmd/api/api.md)
    * To manage the ingestion, and accession of the generated metadata files
    * And to create the requested On Demand Dataset
* A Postgres Database to store and manage created On Demand Dataset

The bp-dod-sda-gateway hosts two [connectrpc](https://connectrpc.com/) servers
The public [dataset_on_demand_service.proto](proto/public/v1/dataset_on_demand_service.proto), at port specified by  --dod_service.port flag.
The private [dataset_on_demand_admin_service.proto](proto/private/v1/dataset_on_demand_admin_service.proto), at port specified by --dod_admin_service.port flag.

Protobuf code is generated with [buf](https://buf.build/) and the generated code is available at [grpc_gen](grpc_gen).

To generate code run the following command:

```bash
buf generate
```
