# Big Picture Dataset On Demand Sensitive Data Archive Gateway (bp-dod-sda-gateway)

The bp-dod-sda-gateway is responsible for the Dataset On Demand creation in the BigPicture Project.

## Description

The bp-dod-sda-gateway integrates with:
* The [Metadata-Submitter](https://github.com/CSCfi/metadata-submitter/) Postgres Database
  * To get the origin dataset metadata and file accesission ids.
* The [Sensitive Data Archive s3inbox](https://github.com/neicnordic/sensitive-data-archive/blob/main/sda/cmd/s3inbox/s3inbox.md)
  * To upload the generated metadata files for the requested Dataset On Demand Dataset
* The [Sensitive Data Archive api](https://github.com/neicnordic/sensitive-data-archive/blob/main/sda/cmd/api/api.md)
  * To manage the ingestion, and accession of the generated metadata files
  * And to create the requested Dataset On Demand Dataset
* A Postgres Database to store and manage created Dataset On Demand Dataset

The bp-dod-sda-gateway hosts a [connectrpc](https://connectrpc.com/) server following the [dataset_on_demand_service.proto](proto/v1/dataset_on_demand_service.proto) proto definition.

Protobuf code is generated with [buf](https://buf.build/) and the generated code is available at [grpc_gen](grpc_gen)
```bash
buf generate
```
